# Model card — JokeForge Humor Scorer

## Intended use

Predict a continuous community-response proxy for an English joke, then use the output to rank candidate jokes generated by a separate LLM.

## Architecture

- Transformer encoder: BERT-family model
- Task head: scalar regression output
- Target: log-transformed Reddit upvote score, following the r/Jokes regression framing

## Known limitations

- The output reflects a proxy label, not an absolute judgment of humor.
- Humor changes with language, culture, context, time, and audience.
- Popularity feedback can be confounded by post visibility and community behavior.
- Training examples may contain offensive or adult content.
- A model checkpoint is not runnable until actual weight files are present and loadable.

## Reporting requirements

Every released checkpoint should state the base model, data version, preprocessing, label transform, train, development, and test split, seed, epoch, and evaluation metrics.
