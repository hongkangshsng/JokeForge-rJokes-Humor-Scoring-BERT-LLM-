# Results

Only reproducible project results belong in this directory.

Recommended tracked files:

- metrics_by_epoch.csv
- figures/epoch_comparison.png
- prediction_examples.csv with reviewed, non-sensitive examples
- evaluation_protocol.md

The reference paper's BERT, RoBERTa, and XLNet numbers are research baselines, not results from this repository. Add project metrics only after the associated checkpoint and evaluation command are available.
